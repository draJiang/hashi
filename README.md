# hashi

Hashi turns spoken words into real-time translated subtitles, right on your Mac.


https://github.com/user-attachments/assets/dc2e2def-9676-4408-8972-ff748092dd7a

## Usage
1. [Download](https://github.com/draJiang/hashi/releases/latest/)

2. Install the app: Mount the DMG file and drag SimInt.app into the Applications folder.

3. Remove quarantine attribute (required, otherwise the app cannot be opened) Open Terminal and paste:
`xattr -cr /Applications/Hashi.app`

4. Launch the app. When prompted, enter your [License Key](https://jiang.lemonsqueezy.com/checkout/buy/dd55dd4c-5ca1-4ef8-b231-041e340107b1).
